AI250 BXR Firmware
New optional firmware available

Firmware v1.2 is now available.

This update changes the Function control so that its behavior more closely matches the markings on the BXR front panel. It removes the passthrough region present in earlier firmware.

Updating is optional. If you prefer the behavior of the existing firmware, you do not need to update.

Firmware versions
v1.2 — Function control behavior revised; removes passthrough region.
v1.1 — Original firmware.
